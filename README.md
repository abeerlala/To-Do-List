# ✅ To-Do List – JavaScript Practice Project

## 🔗 For Live Demo <a href="https://abeerlala.github.io/To-Do-List" target="_blank">Click Here</a>

This is a simple and functional **To-Do List** application built using **HTML**, **CSS**, and **JavaScript**. It allows users to add, delete, and manage their daily tasks efficiently. I made this project to practice DOM manipulation and event handling.

## ✨ Features

- Add new tasks
- Delete individual tasks
- Mark tasks as completed
- Clean and minimal UI
- Tasks persist during session (if localStorage is used)

## 🚀 Technologies Used

- **HTML** – for the structure
- **CSS** – for layout and styling
- **JavaScript** – for interactivity and logic

## 🧠 What I Learned

- Creating dynamic elements using JavaScript
- Handling user input and form validation
- Using event listeners and managing events
- Optionally, using **localStorage** for data persistence
